# Store preview video (optional)

Record **15–30 seconds** of gameplay for App Store Connect and Google Play where the consoles offer a preview slot.

- **iOS Simulator:** File → Record Screen (or `xcrun simctl io booted recordVideo preview.mp4`).
- **Android emulator:** toolbar **Record** / `adb screenrecord`.
- Trim in QuickTime / DaVinci Resolve; export H.264, match each store’s max duration and resolution limits (see current console help).
